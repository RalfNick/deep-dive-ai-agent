## 作者提供的扫描版学习资料

视觉核对了《AI学习资料》PDF 第 21—22 页。可用信息仅限于入门层面的两点：

1. RAG 由检索系统与生成模型协作，把外部知识放入回答过程；
2. 向量检索把文本映射为可比较的向量，用相似性寻找候选内容。

这两页适合作为中文初学者措辞的辅助参考，不是算法、框架或产品事实的一手来源。技术定义和当前 API 仍以原始论文与官方文档为准。
