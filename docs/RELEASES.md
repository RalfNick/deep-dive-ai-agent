# 发布物规则

仓库只保存可审阅的 Markdown、SVG/必要图片、实验代码、固定报告和测试，不提交 PDF、EPUB、HTML 构建目录或逐页渲染缓存。

## 当前状态

- 简体中文第 1–6 章原稿与配套实验已进入仓库。
- PDF、EPUB 和英文版尚未在本仓库发布。
- 历史工程中的 Chapter 6 `v1.0` / `v1.0.1` PDF 及稳定预览没有迁入 Git 历史。
- `chapter6/tests/test_pdf_release.py` 随本地 PDF 二进制一并排除；因此迁移后的 `chapter6/requirements.txt` 如实保持标准库依赖，不再为已排除的测试声明 `pypdf`。

## 后续发布流程

1. 从已标记的简体中文提交构建 PDF/EPUB。
2. 在隔离输出目录完成字体、图片、链接、目录、分页、Secret 和本机路径检查。
3. 记录页数、字节数、SHA-256、源提交和构建工具版本。
4. 通过 GitHub Releases 上传二进制，不把二进制回填到 `main`。
5. 只有 Release 资产和公开下载链接均已验证后，README 才能标记为“已发布”。

发布标签应采用独立仓库的新命名空间，不移动或复用原工程 tag。旧工程中的二进制哈希仅作为历史审计证据，不能替代新仓库的重新构建与验收。
