# 多语言与翻译合同

简体中文 `book/` 是当前唯一权威正文。英文目录 `book-en/` 处于 `planned`；暂不建立繁体中文目录。

## 状态转换

翻译状态只允许按以下顺序推进：

`planned -> active -> reviewed -> published`

- `planned`：只有语言说明和贡献规则，没有译文章节。
- `active`：已固定简体中文源提交，允许逐章翻译，但不得宣称完整。
- `reviewed`：章节已完成技术、语言、链接和证据边界 Review。
- `published`：对应站点或 Release 已验收，导航和状态已同步。

任何状态回退都应说明原因；不得用空白章节、机器直译占位或未审内容跳过状态。

## 开始英文翻译的前置条件

1. 在 `book-en/README.md` 记录 40 位简体中文源提交。
2. 把 `status` 从 `planned` 改为 `active`。
3. 先翻译 `introduction.md`，再按章节顺序推进。
4. 为翻译 PR 指定语言 Review 与技术 Review。

## 文件与证据对齐

- 中文 `book/chapterN.md` 对应英文 `book-en/chapterN.md`，文件名必须一致。
- 图片优先复用语言中立的原图；图中文字需要翻译时使用独立、可追溯文件，不覆盖中文原图。
- 实验目录和命令保持同一实现，不复制出第二套代码。
- 数字、代码路径、来源 ID、脚注、Claims、Non-claims、练习和参考答案必须逐项对齐。
- 中文源提交变化后，英文版必须标记 drift，复核完成前不能继续声称 `published`。

翻译不是重新创作产品事实。遇到快变 API、模型或产品说明时，应先更新中文来源台账并复核正文，再同步译文。
