## 代码责任

`chapter10/catalog.py`：注册目录、硬权限过滤、确定性关键词检索、完整定义加载预算、版本与权限再检查。目录中的多数工具仅是定义夹具，不假装连接真实系统。

`chapter10/jobs.py`：SQLite 作业状态，提交去重、参数冲突、原子领取、租约和尝试代次、重试、合作取消、截止时间、事件游标、结果引用；只保证本地数据库事务内的副作用一致性。

`chapter10/concurrency.py`：固定数量 worker 消费有限读操作列表，真实协程并发，结果按调用 ID 关联；异常不吞掉取消。

`chapter10/experiments.py`：五组可运行示例和确定性报告。逻辑时间用于故障注入，不报告虚构的网络延迟、Token 或成功率。
