# 第 17 章《多模态与实时 Agent》设计规格

日期：2026-09-30。状态：章法已获用户确认；此规格待用户审阅，尚未进入实施计划或正文写作。执行方式沿用 native。本地分支 `codex/chapter17-multimodal-realtime` 从第 16 章 RC2 的 `1e95c112b20a72c6622be5a4dcfcce1346aa6ee3` 创建。

## 1. 目的、读者与可验收结果

读者已学过 Agent Loop、上下文、工具、权限、评估、Trace 和持续改进，但未系统理解图片、语音、屏幕与连续事件怎样改变 Agent 的证据合同。本章的核心问题是：**Agent 看见一张图、听见一句话或收到一帧屏幕之后，凭什么据此回答或行动？**

读完本章，读者应能：

1. 区分图像中的可观察内容、由观察推得的数值、外部数据的核验结果，以及模型或 Agent 给出的最终结论。
2. 用图表的小例子手算变化率，指出截断坐标轴、图例不清、单位不明和图表与数据不一致时应怎样表达未知。
3. 解释 Computer Use 的观察—定位—授权—行动—复核流程，并指出截图坐标与实际显示坐标、画面版本和执行回执各由谁负责。
4. 解释转写式语音管线、原生实时会话与“语音前台＋任务后台”各适用什么问题；能区分打断播报、截断未播放内容和取消后台任务。
5. 跑通无需 API Key 的最小图表验证与事件流实验，看到中间证据、失败样本和明确的结论边界。
6. 把多模态输入的来源、时间、范围和权限条件接到第 16 章的失败回放与第 18 章的最终系统，而不是把“模型看懂了”当成完整验收。

成功交付以读者实际能解释上述边界、执行命令并复核固定报告为准，不以长篇术语清单或最新产品名称的数量衡量。正文目标约 2.0–2.5 万叙述汉字、约 28–36 个二三级标题、7 幅原创技术图、4–5 张比较表、5 组实验、至少 4 个失败样本和 13 道分层练习。统计叙述汉字与包含代码及 Markdown 的总字符数时分别记录；不靠重复免责声明凑篇幅。

## 2. 已确认的章法和相邻章节边界

采用**一个可复算的主案例＋若干短反例**。主案例是作者自制的月度业务图表：一月 80、二月 100，单位“千件”。用户问“二月比一月增长多少？”读者先在图上找指标、刻度、单位和对应月份，再按 `(100 − 80) / 80 = 25%` 手算；Agent 的限定图表观察器给出有来源的候选数值，代码用独立 CSV 核对，再形成可解释答案。图表或数据一旦冲突，不能悄悄换成 CSV 数字并声称它来自图；结论应保留冲突和待澄清项。

第二个短案例用两帧模拟桌面截图说明 Computer Use：上一帧按钮位置有效，不代表下一帧仍有效。第三个短案例用固定语音事件记录说明用户打断：停止播放只是语音层事件，尚未完成或取消的后台核验不能被口头“已停止”掩盖。三例共享一条简明的证据链，但不强迫共用同一业务问题。

另两种方案不作为本章主线：多模态技术百科覆盖广却难以形成可复核结论；从零实现完整语音桌面助手需要真实权限、麦克风、屏幕与 Provider 环境，会把接口搭建挤到概念之前。本章采用离线教学核心，在较短的产品对照节介绍可选真实接入的责任边界，不部署服务。

第 13 章已经讲过评分统计，第 14 章已经讲过 Trace，第 16 章已经讲过失败转资产；本章只添加多模态特有的观察证据、空间坐标和时间事件，不重做那些体系。第 18 章负责委派、多 Agent、部署和最终综合项目；本章不实现多 Agent 平台、生产语音客服或通用 Computer Use 自动化。

## 3. 正文的四幕阅读路径

1. **看见不等于读对。** 用图表问题开场，解释图像、文本、文档页、音频和屏幕帧进入上下文的形态；以 OCR/结构提取/视觉模型的能力边界为对照。先让读者自己读图，不先展示完整数据结构。
2. **读到不等于算对。** 从图表元素、坐标轴和单位取数，手算变化率，再让代码核对；通过截断轴、图例含混、来源冲突和零分母展示失败语义。一次可信的回答需能反向指到图表区域、派生步骤和核验结果。
3. **看见不等于获准行动。** 从屏幕帧到目标定位、坐标变换、权限/确认、模拟执行和新截图核验；说明图中文字是待处理内容，不会自动成为用户授权。截图过期、窗口改变或执行失败时刷新观察/请求确认，不继续盲点。
4. **实时不等于一条更快的文本消息。** 以带序号的事件线解释语音输入、识别或原生音频处理、模型播报、用户插话、工具任务和完成回执；区分播报中断、会话上下文截断、后台任务取消、任务已经提交的不可撤销副作用。末尾比较适用场景、成本构成与安全边界，接向下一章。

约 30 个小节服务上述四幕，不为凑目录逐一罗列模型或 SDK。正文按“现象→最小定义→手算→代码中间结果→反例→产品映射→取舍”的阅读节奏；将完整事件 Schema、接口参数、表格原始夹具和长日志放入配套材料。图与表必须在正文解释读图/读表顺序。

## 4. 最小教学系统与数据合同

实验包为独立的 `chapter17/`，运行时优先 Python 标准库，测试依赖沿用本书锁定习惯。它不依赖第 16 章内部实现；必要时只采用上一章公开的来源、Unknown 和回放原则。默认不读取密钥、不联网、不控制真实桌面、不录音，不要求 Docker、GPU、外部 OCR 或模型服务。

从输入到答案/行动的责任链是：

`带身份的媒体或事件 → 限定观察器 → 来源/时间/坐标检查 → 计算或行动提议 → 权限与新鲜度门禁 → 模拟执行 → 结果核验 → 答案及证据`。

数据结构的最小字段：

| 记录 | 必需内容 | 不允许偷换的含义 |
| --- | --- | --- |
| `MediaRef` | 媒体种类、来源标识、内容摘要、页/帧、采集时刻、可用范围 | 文件名、画面内文字和模型描述都不是授权 |
| `Observation` | 观察方法、图表/屏幕区域、候选读数与单位、来源引用、歧义或缺项 | “置信”不能替代刻度、图例和数据核对 |
| `Decision` | 回答/询问/刷新/行动提议及其依赖的观察 | 模型提议不等于已执行动作 |
| `ActionReceipt` | 原画面 ID、坐标空间与换算、授权状态、实际模拟执行、后验画面 | “已说完成”不能代替回执或后验状态 |
| `EventRecord` | 序号、事件时间、会话/轮次/后台任务 ID、事件种类、结果 | 停播与取消后台任务分开记录 |

第一个观察器仅支持作者控制的 SVG 柱状图夹具：从刻度文本、柱形几何和图例的受限约定提取数值，用独立 CSV 验算。它是**受限矢量图结构解析**，不是通用 PNG/照片 OCR，也不是已验证的视觉模型能力；如轴或图例超出支持范围，返回 `unknown` 并指出缺少的证据。静态 PNG、文档页和语音输入在离线实验里采用明确标注的固定观察结果，供后续控制逻辑测试，绝不写成“本章离线模型识别成功”。正文介绍真实 VLM/语音组件替换该接口时还需要什么额外评估。

屏幕实验只在版本化夹具上计算坐标并写模拟回执；它不发送真实鼠标键盘事件。事件实验采用本书定义的中性 `EventRecord`，映射真实 API 时注明字段、版本和差异，不冒充 OpenAI 或 Anthropic 原始协议日志。未知、冲突、过期和缺授权是显式结果，不能吞并到“失败”或“成功”。

## 5. 五组实验和预期观察

1. **图表取数与代码复核。** 展示 SVG 的刻度、柱高、两个月候选值、CSV 对照、手算与代码得到的 25%；答案引用图与计算来源。另输出一个仅靠视觉比例误判增幅的失败样本。
2. **视觉歧义与冲突。** 注入从 70 开始但刻度完整标出的纵轴，正确结果仍应是 25%，不能按柱子的可见高度比例计算；若刻度缺失、图例混淆、单位不明、分母为零或图/CSV 冲突，则逐条给出 `unknown` 或有范围的结论，不以“生成流畅的解释”算通过。
3. **Computer Use 的陈旧帧。** 固定两个不同布局的截图夹具，对同一提议分别验证坐标缩放、帧身份、确认与后验状态。旧帧、超界坐标、缺授权和画面中伪造指令必须阻断；没有真实 UI 副作用。
4. **语音打断与后台任务。** 固定事件时钟与序号，观察用户插话、停止播放、未播放内容从对话状态移除、后台核验继续或显式取消的两条支路。乱序/重复事件与已完成任务的晚到取消必须有确定性处理；不以模拟步数冒充真实时延。
5. **跨模态证据与安全复盘。** 将图、文档页、语音文本、屏幕帧的来源与时间连接到同一报告；注入不可信画面中的越权指令、过期图表和缺回执，比较清晰回答、保留未知、拒绝行动三种结果。说明哪些证据能进入第 16 章的失败回放包。

每组实验记录固定输入、版本和时钟、关键中间状态、失败原因及已证明/未证明结论。统计只使用有分母的任务数、证据覆盖数、违规数和事件不变量；不报告未测量的 Provider Token、费用、实时延迟或真实模型正确率。输出已有路径必须拒绝覆盖，规范报告两次运行在新目录下逐字节一致。

## 6. 图、练习与来源

七幅图使用本书浅色纸张、手绘描边与蓝绿紫橙分区；所有中文、数字、轴与箭头由可控矢量排版，提供设计源和图文核对记录：

1. “增长多少？”的可复算主图：月份、单位、刻度与隐藏的误读入口。
2. 五类输入到统一证据链：图像、文档页、屏幕、音频、文本各自带什么身份。
3. 图表观察→算数验证→回答；冲突怎样分流到 `unknown`。
4. Computer Use 的观察→坐标映射→确认→行动→复核闭环。
5. 旧帧与新帧：同一坐标为何可能指向不同控件。
6. 实时语音的双时间线：用户打断、播报停止与后台任务状态。
7. 跨模态来源/时间/权限门禁与失败回放包。

第一图既是正文配图，也可与独立实验夹具共享绘制规范；实验夹具仍在 `chapter17/fixtures/` 保存可运行版本，不能拿被美术加工过的封面图冒充测试输入。设计源放 `infographic/chapter17/`，正文章图放 `book/images/chapter17/`。桌面与手机预览均要检查图内文字、表格滚动、图号和图文对应。

13 道练习分为解释、手算、修改夹具和设计验收四层。至少提供一次可复算的 80→100 变化率、一次截断轴反例、一次坐标缩放计算、一次中断事件排序；计算题写出数值答案和过程，代码题可运行，设计题有否决判据。

来源台账至少覆盖 [ChartQA](https://arxiv.org/abs/2203.10244)、[ChartQAPro](https://arxiv.org/abs/2504.05506) 和 [ScreenSpot-Pro](https://arxiv.org/abs/2504.07981) 的问题定义；[OpenAI 图像与视觉限制](https://developers.openai.com/api/docs/guides/images-vision)、[Realtime 中断与截断](https://developers.openai.com/api/docs/guides/realtime-conversations#interruption-and-truncation)、[GPT-Live 前后台职责](https://developers.openai.com/api/docs/guides/live)、[OpenAI Computer Use](https://developers.openai.com/api/docs/guides/tools-computer-use) 与 [Anthropic Computer Use](https://platform.claude.com/docs/en/agents-and-tools/tool-use/computer-use-tool) 的官方说明，以及本章固定报告。设计时资料核对于 2026-09-29 至 2026-09-30；正文实施时逐条复核并记录版本/日期。论文结论、厂商提供的功能和本章离线实验结果不能互相冒充，不写厂商排名或易过期价格清单。

## 8. 设计自检与下一步

本设计仅覆盖一章书稿和一个可运行的最小教学包，代码不是通用多模态框架。真实图像、语音识别、Computer Use 操作、生产延迟和模型质量的结论必须留待将来真实接入及独立评估；本章可证明的是受控输入下证据链与运行边界怎样工作。五组实验分别对应正文问题，并提供错误结果而非只有成功样例。
