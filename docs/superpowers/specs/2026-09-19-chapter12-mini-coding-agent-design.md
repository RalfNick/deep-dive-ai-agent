# 第 12 章设计：手写一个 Mini Coding Agent

日期：2026-09-19。状态：书面设计已获用户确认；不是已完成书稿。原待审阅版本保留在 Git 提交 3384ce6 中。

基线：第 11 章 v1.0-rc2，提交 2f9eb51。用户已确认将 Pi 纳入第 12 章的建议：Python 手写实现为主线，Pi 为核心源码参照，保留 LangGraph 与 OpenAI Agents SDK 的重构对照。章名和 18 章总体结构不变。

## 设计与读者目标

这是包含新运行时与配套书稿的架构级工作。目标不是实现另一个完整商业编码产品，而是让已有基础 Python 知识的读者理解并运行一个真正由模型选择行动的 Coding Agent。

读者读完后，应能解释一次任务中哪些内容来自模型，哪些行为由程序强制；能修改一个工具、定位一次失败、检查一次审批恢复，并用测试与差异判断任务是否完成。最小的意思是职责数量受控，不是删除验证、安全或停止条件。

写法延续用户明确的偏好：先看一个可运行例子，再逐步拆开；术语在问题出现之后解释；例子服务于本章，不要求强行贯穿整本书。参考《从零构建大模型》的渐进教学取向，不复制其文字或图像。

## 已选路线与取舍

采用“手写完整闭环 → 逐步增加运行边界 → 对照 Pi → 两种框架重构”。

- 不从 SDK 入口开始：这样虽然更快得到演示，却难以分清框架替读者完成了哪些工作。
- 不逐节更换业务案例：本章需要观察同一任务的状态如何跨工具、审批和恢复流转；案例太散会增加理解成本。
- 不增加第三套完整 Pi 移植：Pi 承担源码参照和职责映射，避免 Python 与 TypeScript 双主线。LangGraph 与 Agent SDK 两套可运行重构仍属于原定交付，不能因为加入 Pi 而被删掉。

本章不开发 Web UI、插件市场、通用多 Agent 平台或远程生产部署。第 13 章再系统设计任务集与评估，第 14 章再展开跨任务 tracing、成本和生产诊断。这里仍提供完整的单次运行轨迹与验收证据，不以“留给下一章”为由删掉基本可观察性。

## 案例合同

采用一个独立、自包含的 Markdown 链接检查器教学仓库。复用第 11 章读者已理解的嵌套相对链接错误，但不导入 chapter11 的修复函数，也不把正确补丁写入模型任务提示。

任务文本只提供用户现象、示例输入、约束和验收要求。Agent 需要自行查找活动实现，检查已有测试，添加能复现问题的回归，修复源码并运行验证。仓库包含活动实现、旧示例、用户未完成笔记、根目录有效链接、嵌套有效链接、真正缺失链接和外部链接。

这次演示和第 11 章的区别是决策来源：第 11 章的固定程序知道修复步骤；第 12 章运行时只提供动作接口和规则，真实模型必须从工具观察中选择步骤。标准回放仍可预先固定决策，但必须显式标为回放，不能作为模型自行诊断的证据。

增加一个嵌套文档同时包含有效与缺失链接的变体，用来拒绝“所有链接都返回空列表”的假修复。这个变体是行为边界检查，不称为未见任务泛化测评。

模型只能在每次运行新建的教学工作区内提出修改，不接触读者业务仓库。已有用户笔记和无关文件必须保留。除回归测试外，独立验收样本由宿主保管，不允许候选修改自身验收标准。

## 正文结构与阅读节奏

目标 20,000–30,000 中文字符、约 30–36 个二三级标题、7 幅图、5 组实验、14 道练习。字数用于保证解释充分，不用重复声明填充。

### 第一段：先让读者看到它工作

1. 从“请帮我修一下这个仓库”开始：显示任务、第一次读取、失败测试、补丁与验收的完整短轨迹。
2. 它和固定修复脚本有什么不同：对比工具观察改变后下一步决策的来源。
3. 第一次运行：离线回放先看事件，再给出真实模型入口；明确命令在哪个目录运行。
4. 一张总图：模型、消息、五个工具、执行环境与验收器分别在哪里。

开场的真实运行记录必须来自完成后的实际执行；写作阶段没有证据时，不预填成功叙事。可以先展示离线机制，但最终书稿要准确区分两种运行。

### 第二段：一轮行动怎样发生

5. 模型返回的是文字还是工具提议：从一份具体响应讲起。
6. 读取与搜索：范围、行号、截断提示和错误返回。
7. 补丁编辑：为什么要确认旧内容与文件版本。
8. 执行测试与查看差异：日志不是验收回执。
9. 让工具结果进入下一轮：关联调用与结果，避免消息配对失效。
10. 写出第一版循环：模型提议、校验、执行、回传与继续。
11. 计划怎样帮助工作：记录下一步与验收条件，不要求模型暴露内部思维链。

每节先给一个小输入及对应输出，再展示最少代码。完整类型、边界表和辅助函数放入配套代码，正文不连续堆放整文件。

### 第三段：从会行动到受控运行

12. 模型说完成以后：通过独立验收才能交付。
13. 少一条规则会发生什么：未知工具、错误参数、截断响应、测试失败。
14. 审批：批准的是这次具体修改，而不是以后所有写操作。
15. 执行隔离：进程在哪里运行，能看到什么，能连接哪里。
16. 暂停与恢复：保存任务状态，重新核对现场，不重复写入。
17. 上下文压缩：保留目标、约束、待审批动作和最近失败证据。
18. 停止：成功、拒绝、取消、异常和预算耗尽不是同一种结束。
19. 读一次 Trace：从失败事件回到对应工具、文件版本和运行阶段。

只把第 4、6、9、10 章的必要机制接入本次 Agent，不重新写一遍机制百科。

### 第四段：回到真实开源项目与框架

20. 对照 Pi 的三层：模型适配、Agent Core、Coding Agent。
21. 沿 Pi 源码读一轮调用：上下文转换、工具执行、消息回传与事件。
22. Pi 的扩展与安全边界：可以扩展，不代表默认隔离。
23. 用 LangGraph 重构：节点、状态、条件边和持久审批。
24. 用 OpenAI Agents SDK 重构：工具注册、运行、审批与会话适配。
25. 同一任务比较三种实现：代码责任转移到哪里，而不只比较行数。
26. 本章小结、分层练习、限制与下一章评估衔接。

其中工具、循环、恢复及重构小节使用必要的三级标题，使标题总数保持在写作标准内；不为达到标题数量拆散自然论述。

## 五个基础工具与组件边界

所有模型动作经过同一个执行网关，框架重构不得绕过这条路径。第一版单次执行一个工具，不引入并发写操作。

| 工具 | 输入与返回 | 强制边界 |
| --- | --- | --- |
| read_file | 相对路径、行范围；返回文本、行号、内容版本、截断标记 | 工作区路径约束、文件大小限制；不读宿主凭据 |
| search | 查询、允许目录；返回命中片段与位置 | 固定输出预算；无匹配与被截断分开 |
| apply_patch | 路径、读取版本、精确替换块；返回新版本和差异 | 修改范围、旧版本与唯一匹配检查；需要审批 |
| run_tests | 预设测试任务名；返回退出状态、发现数量、诊断和日志引用 | 不接受任意宿主 shell 文本；在执行后端中运行 |
| show_diff | 当前任务工作区；返回相对路径和差异 | 只读、输出受限、不执行仓库提供的外部 diff 程序 |

任务计划和请求完成属于结构化决策或运行状态，不为了凑功能再加入任意 shell、联网、部署或推送工具。模型给出的计划只是可检查的工作说明，不是可信执行指令，也不是隐藏推理过程的记录。

组件分工如下，文件名属于未来实现合同，本次不创建空壳程序：

- `chapter12/contracts.py`：模型决策、工具提议、结果、错误类别、运行状态与预算。
- `chapter12/providers/`：真实模型适配与离线 ReplayModel；同一运行时支持二者，不在模型适配里偷偷修代码。
- `chapter12/tools.py`：五个工具的输入输出和业务行为；不承担整个 Agent 循环。
- `chapter12/executor.py`：工作区、路径与权限策略、输出上限、期限和后端选择。
- `chapter12/runtime.py`：下一轮决策、校验、审批、行动与停止。
- `chapter12/state.py`：本地持久状态、动作记录、审批和恢复检查。
- `chapter12/context.py`：消息装配、完整工具调用配对、压缩摘要与保留项。
- `chapter12/verifier.py`：不可由候选自行批准的独立行为验收、文件保护和证据版本。
- `chapter12/trace.py`：逐事件记录、关联与脱敏导出；轨迹查看不重新执行副作用。
- `chapter12/adapters/`：LangGraph 与 OpenAI Agents SDK 的真正编排实现。
- `chapter12/quickstart.py`、`experiments.py`、`exercise_solutions.py`：完整运行、分组场景与练习入口。

## 执行与恢复合同

运行状态至少区分 ready、awaiting_approval、executing、verifying、completed、failed、cancelled、budget_exhausted。只有验收器通过才能写入 completed；模型请求结束不直接产生 completed。审批被拒绝形成显式工具结果，允许模型在剩余预算内提出不越权的替代动作；拒绝不会被偷偷转成允许。

审批记录绑定任务、动作标识、规范化参数和读取到的工作区版本。恢复后文件已改变时旧批准失效，需要重新读取并提出动作；不允许用一份全局布尔批准覆盖未来修改。

补丁执行前记录意图，执行后保存回执。进程在二者之间退出时，恢复程序比较预期前态、后态和当前内容：确认为后态时补记回执；确认为前态时在原权限条件仍成立后继续；不匹配则停止并要求核对。无法确认的副作用不自动重试。教学实现不声称分布式 exactly-once。

只允许单写者运行，通过本地锁或等价机制拒绝两个运行器同时写同一教学目录。锁不替代文件版本检查；外部编辑依然可能发生。检查点不会自动回滚用户文件。

预算包括模型轮数、工具次数、累计运行期限和输出上限；模型调用有单次超时。取消必须停止后续调度，并结束受控执行后端的任务。上下文的字符或字节预算按真实单位命名，不能伪称为 Token。服务端实际 usage 可另外记录。

## 沙箱与真实模型

提供两个明确命名的执行后端：trusted_local 仅用于本书生成的可信夹具和离线教学；container 用于模型驱动的代码执行实验。普通临时目录和 Python 子进程不称为沙箱。真实模型示例默认要求通过环境预检的隔离后端，不能因容器不可用而静默降级到宿主执行。

隔离实验的最低合同：只暴露本次教学工作区；根文件系统只读，提供受限临时写区；执行身份非 root；禁用网络；不挂载宿主用户目录、容器控制 socket 或模型密钥；限制运行时间、进程数量、内存和输出。明确容器共享内核的限制，不声称能防御一切恶意代码。采用版本固定的运行镜像，真实执行边界探针并记录结果。

模型 HTTP 调用由宿主侧受限适配器发起，容器内部只运行本次候选与测试。凭据从环境读取，不进入工作区、提示词、图片、规范报告或 Trace。已有对话中暴露过的密钥不嵌入代码；真实运行前核对当前有效凭据和预算。没有可用凭据时可完成离线机制，但真实模型验证保持未完成，不能宣称本章全部验证结束。

2026-09-19 的环境预检只证明有 Ubuntu WSL，当前 Windows PATH 未发现 Docker 或 Podman，当前解释器未安装 LangGraph 与 openai-agents。它不证明 WSL 已有容器运行时，也不证明沙箱不可实现。后续应先只读核对现有环境；涉及系统服务或安装范围扩张时另取授权，不擅自变更机器配置。

## 上下文与证据合同

历史消息、持久任务状态与模型输入是不同对象。压缩生成新的模型输入视图，不删除原始 Trace，也不把摘要当作磁盘状态真相。

必须保留：目标、禁止修改项、已批准或待批准动作、验收要求、最近一次失败的测试名和差异、当前有效文件版本。工具提议与结果不得只留一半。恢复前重查文件，失效证据必须标注，不把旧成功回执当作当前成功。

独立验收资产放在候选可写区域外，以只读方式送入隔离执行。候选测试全绿、未知测试数、零项测试、修改测试来消除断言、恒空返回、无关用户文件被改，均有明确处理。验收也不信任候选在 stdout 中打印的“成功 JSON”。运行记录说明验收的信任边界；对主动对抗程序不作超出实验的安全承诺。

最终交付包含源码与回归 diff、命令、测试发现数量、失败到通过证据、独立验收、保留项检查、工作区版本和未覆盖内容。真实模型会话不收集或展示隐藏思维链，只记录可见消息、工具参数与结果、状态和实际用量。

## 两种框架重构

三种实现共享任务、工具接口、执行网关、独立验收和事件语义，变动项是编排层。LangGraph 版本需要由图节点、条件边与持久状态实际控制下一步；Agent SDK 版本需要由 SDK 的模型与工具运行机制控制下一步。不能只在框架节点或工具函数内包住整个手写循环，然后称为重构。

各版本至少验证正常工具循环、写操作审批暂停及跨进程恢复、失败后的继续或停止、模型提前宣布完成被验收拒绝。框架原生机制与本章额外编写的适配部分明确标注。

运行前固定依赖版本。离线适配测试可以用模型测试替身，但必须执行真实框架代码；缺包时测试不能以自动跳过伪装成框架验证通过。真实模型运行与机制回放分别报告，不要求不可重复的自然语言输出逐字一致。

比较维度为代码职责、状态可见性、控制权、恢复接口、错误定位、依赖与维护负担。行数只能作为附带观察，不用单任务结果评判模型或框架优劣。

## 五组实验与输出

| 实验 | 场景 | 必须看见的证据 |
| --- | --- | --- |
| 12-1 完整闭环 | 先离线观察，再通过真实模型提出工具调用，完成链接修复 | 决策来源、读取、目标红灯、补丁、独立验收和最终 diff；两类记录分开 |
| 12-2 工具与失败 | 未知工具、无效参数、输出截断、过期补丁、恒空返回 | 校验或执行发生在哪层；拒绝前无副作用；错误进入后续观察；假完成被拒绝 |
| 12-3 审批与恢复 | 写入前暂停，进程退出；批准后恢复；文件变更使批准失效；执行后回执前崩溃 | 持久审批内容、恢复读取、动作状态、重复写入检测和不确定状态停止 |
| 12-4 上下文与隔离 | 长日志触发压缩；读取越界、联网和资源耗尽探针；取消与预算耗尽 | 压缩前后保留项、实际隔离拒绝结果、期限与停止原因；不把模拟拒绝当 OS 隔离 |
| 12-5 框架对照 | 同一组任务与协议分别运行手写、LangGraph、Agent SDK | 三套真实编排入口、统一验收、审批恢复轨迹和职责比较 |
