# 第 2 章练习参考答案

参考答案用于自检，不是唯一写法。设计题应优先检查证据链、边界和验收标准，而不是是否使用了相同术语。

## 基础题

1. **预训练、SFT 与上下文学习**：预训练从大规模序列学习通用下一 Token 分布；SFT 用精选输入—输出示范继续更新权重、塑造行为；上下文学习只在本次输入中提供规则或示例，通常不更新权重。预训练与 SFT 都可使用交叉熵，但数据、mask 与目的不同。
2. **对齐不是一个分数**：指令对齐可测合法请求遵循率，事实性可测可核查主张正确率，任务成功可测环境验收通过率。模型可能更严格地遵循“给出五条结论”的格式，却因引用过期导致事实性下降；也可能通过测试，但靠越权修改而任务治理失败。
3. **为什么 assistant-only mask 不是细节**：若用户、系统与助手 Token 全部计入损失，模型也在优化复现提示；只训练助手部分则把预算集中在目标回答。被遮罩 Token 仍参与前向计算和注意力，只是不直接贡献这些位置的损失。角色起始标记是否训练取决于模板与生成起点。
4. **DPO 标签表达什么**：在同一提示和既定 rubric 下，chosen 相对 rejected 更受偏好；它不直接给出绝对分数，也不保证 chosen 事实正确、安全、可执行或在分布外仍然更好。
5. **采样、推理与硬上限**：temperature 改变分布尖锐程度，top-p 截断候选集合，reasoning effort 调节模型投入工作的档位，最大输出 Token 更接近生成硬上限。低温度只集中既有概率，最高 effort 也可能放大错误前提，二者都必须由任务评估校准。
6. **Structured Outputs 与工具调用**：前者约束模型返回的数据形状；后者是模型请求应用执行某项能力的协议。工具参数可以结构化，但真正的执行、鉴权、幂等、审批和结果验证由应用负责。

## 实验题

7. 在 `sft_mask_demo.py` 中让 `<assistant>` 不作为训练目标，会少一个有效位置。若推理运行时预先注入该标记，遮罩可能合理；若模型必须从用户消息后自己生成角色起始标记，训练它通常更一致。答案必须同时描述训练模板和部署生成起点。
8. `real_sft_evidence.py` 的比较至少报告目标损失、六题成功率和保留集损失。混入通用样本可能缓解遗忘，却也可能稀释目标梯度；减半步数可能降低过拟合，也可能让目标行为尚未学会。应固定 seed，保留基线，并完整报告两种模型而不是挑最好结果。
9. 在 `preference_demo.py` 中提高 `beta`，初始梯度绝对值通常增大，偏好边界更陡；过大的设置可能使训练对噪声标签更敏感。应画出多个 beta 的损失与间隔曲线，而不是只比较最后一步。
10. 当危险动作拥有最高 logit 时，greedy 会每次选择它，低温度也会提高它的集中度；top-p 只有在阈值和其他概率恰好把它排除时才可能移除它，不能充当安全策略。正确修复是改上下文、模型或外部权限/验证，不是盲调采样。
11. 入口岔路多的迷宫可能拥有很短的最优路径，却在找到它前展开大量无关节点。答案长度描述最终路径，搜索难度还受分支因子、启发式和验证信号影响，所以“短答案”不等于“低推理成本”。
12. 提高安全门槛会先过滤 safety pass 较低的配置，提高容量门槛会过滤低 RPM 配置；具体结果以脚本输出为准。硬门槛失败必须保留原因，不能让普通任务高分在加权平均中抵消权限违规或容量不足。

## 设计与批判题

13. **客服路由评估**：至少包含常见意图、长尾意图、拒识、越权请求、工具失败和多轮改口；指标包括路由正确率、关键错误代价、p95 延迟、每单成本与人工升级率。先达到安全/准确门槛，再优化成本。
14. **偏好数据质量**：记录标注规范、标注者一致性、顺序随机化、长度偏差、争议样本和分布切分；用保留集做人评，不用训练偏好模型同时充当唯一最终裁判。
15. **推理预算路由**：简单任务先走低 effort；只有置信度低、验证失败或任务被分类为高风险时升级。对升级率、最终成功率和额外成本做联合评估，并设置总 Token、工具次数、时间和费用停止条件。
16. **结构化补丁计划**：Schema 约束文件、行号、操作、风险等级和测试；语义层检查行号顺序与文件存在；策略层验证路径在仓库内、危险目录禁写、需要审批的风险等级；执行层使用沙箱并在修改后运行测试。`{"file":"../secret","operation":"patch"}` 可以结构合法却必须拒绝。
17. **证据升级**：固定开放权重模型与提交版本、公开训练/验证/保留集、完整模板和 loss mask、硬件与精度、随机种子、学习率与步数；设置无训练、SFT、数据混合等基线；至少多次重复并报告均值、方差或置信区间；同时测目标成功、保留能力、安全、长度、成本与吞吐。采样实验还要固定解码实现，偏好实验还要记录 KL、奖励分布和人评一致性。
