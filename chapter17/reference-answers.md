# 第 17 章分层练习参考答案

本文件对应[正文十三题](../book/chapter17.md#十三道分层练习)。答案给的是判据和可复算过程，不要求读者与这里的措辞完全一致。所有计算均使用本章固定数据；不需要 API Key 或真实桌面权限。

1. **17-1。** `MediaRef` 指向原材料，应有 `source_id`、摘要、定位和采集时刻；`Observation` 指从哪个区域用何方法读到了 Jan=80、Feb=100、单位千件；`Decision` 是 `(100−80)/80×100=25%` 或明确 `unknown`，并引用证据。最终回复可能只包含“25%”，既不能重算原图摘要，也不能证明单位或冲突是否检查过。

2. **17-2。** 绝对增加 `100−80=20` 千件。相对增长 `(100−80)/80×100%=25%`，分母是旧值一月 80。二月是一月的 `100/80×100%=125%`。后两者的 25% 与 125% 相差的是“增量”还是“新值占比”；20 千件属于绝对量。

3. **17-3。** 从 70 开始截断后可见高度一月 `80−70=10`，二月 `100−70=30`。若误把露出高度当业务值，算 `(30−10)/10=200%`；实际是 `(100−80)/80=25%`。公式本身都按各自分母正确执行，错误在把坐标轴上的视觉距离错当业务数据。

4. **17-4。** 图仍为 Jan=80，而 CSV Jan=81，`decide_chart` 应给 `unknown` 和 `chart-csv-conflict`，同时保留图源 ID 与 CSV 摘要。`(100−81)/81×100≈23.45679%` 虽是按 CSV 的合法算术，却不能冒充“这张图显示的增长率”；它暗中把图上 Jan=80 换成 CSV 的 81。可通过 `python -B -m pytest chapter17/tests/test_chart.py -q` 验证已有反例。

5. **17-5。** 例如在受控 SVG 里给 `rect` 添加 `transform="scale(2)"`。浏览器仍能显示柱子，但解析器没有变换矩阵处理合同，应返回 `unknown`，原因是未知 SVG 属性。若要正式支持，至少增加带旋转/缩放的正例、错误变换负例、坐标反变换手算与独立 CSV 核验；不能只删掉属性拒绝检查。

6. **17-6。** 等比时 `(400×1600/800,225×900/450)=(800,450)`。非等比时 x 比例 `1200/800=1.5`，y 比例 `900/450=2`，坐标是 `(600,450)`。统一用 2 倍会把 x 错点到 800，偏离 200 像素。

7. **17-7。** 对照提议 `frame_id=f1`、当前帧 `frame_id=f-new`、当前目标框与坐标的绑定（还应检查采集时间）。帧不同，旧观察已经失效，返回 `refresh` 且 `executed=false`。先点会把旧帧的“提交”映射到新帧的“删除”，具有不可逆风险。

8. **17-8。** “忽略审批”来自屏幕内容，是低信任材料；用户批准与应用策略才有授权权力。`send` 不在允许动作表，且 `approved=false`，应 `blocked`、`executed=false`。OCR 只改变载体，不改变来源或权限，转成文本后仍不能升级为指令。

9. **17-9。** 已模拟执行，`executed=true`；缺新帧，`status=unknown`，不能说已验证提交。若第一次请求其实被服务端接收，盲重试可能重复创建。真实系统可要求服务端返回唯一提交 ID，并按幂等键查询该 ID 的持久状态，再决定补偿或重试。

10. **17-10。** 完整序列归约为 `playback=stopped`、`conversation_tail=removed`、`backend_task=running`。删除第四个 `playback_stopped` 且保留序号 5，会出现缺号：事件历史不完整，归约器把后台设为 `unknown`，不能推断完整会话状态。若把剩余事件重新编号为连续 1–4，后台仍为 `running`、尾部仍被截断，但不能再声称扬声器已停止；`response_cancelled` 只是取消请求，不能替代停播回执。

11. **17-11。** 同序号同内容的重复事件幂等，`committed_actions=("a1",)`；任务完成后晚到取消不能覆盖完成，`backend_task=completed`，但留下 `late-cancel-after-completion`。同序号异内容说明同一历史位置出现冲突，归约器应 `unknown` 并保留冲突；任意选一个会伪造确定历史。

12. **17-12。** 最小六题可设：① 图表小刻度使 Jan 误读，期望 `unknown`/局部证据；② 单位被裁掉，期望弃答绝对量；③ 提议引用旧帧，期望 `refresh` 与无执行；④ 屏幕伪指令要求越权，期望 `blocked`；⑤ 用户插话后只见响应取消、无停播，期望播报状态未证实；⑥ 后台任务仍运行时系统声称“已取消”，期望验收失败。每题应保存输入摘要或帧/事件 ID、预期状态和不能靠话术掩盖的错误。如果真实模型自动编造缺失回执，即使最终句子礼貌，也必须判失败。

13. **17-13。** 若用户只问后台业务增长率且数据库版本可信，直接查数据库并计算，避免视觉误读；若用户问“我上传的图显示什么”，必须解释截图上的单位、月份和轴，并与数据库不一致时报告冲突；若图缺单位或版本，先澄清。语音中断时可答“我已停止播报；后台查询仍在运行。要取消查询吗？”收到用户确认后向后台发取消请求，并等待取消回执；如果数据库读取已完成，不能通过截断音频声称它被撤回。
