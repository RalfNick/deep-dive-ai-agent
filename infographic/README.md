# Infographic design records

本目录保存全书原创信息图的来源说明、内容结构、生成提示词、候选版本与最终 PNG。正文使用的轻量 WebP 位于 `book/images/`。

每张图的 `refs/` 目录只在作者本地保存，不进入 Git。参考图可能受第三方版权保护，只用于分析视觉层级、配色或构图；公开仓库不再分发这些源媒体。来源链接和使用边界记录在对应的 `source-*.md`、`analysis.md` 与提示词 frontmatter 中。

当前样板：

- `llm-workflow/`：第 1 章“大模型如何工作”；
- `rag-workflow/`：第 8 章“RAG 如何工作”；
- `semantic-code-navigation/`：第 11 章“文本搜索与语义代码图”预备素材。

生成图不能代替事实审校。发布前仍需检查中文文字、技术关系、图片体积、Markdown 引用和站点实际渲染。
