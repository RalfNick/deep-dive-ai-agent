# 第 12 章七幅图技术简报

## 统一视觉

- 用途：书籍正文与微信公众号长文，优先保证手机端可读。
- 参考：用户提供的“大模型如何工作”信息图；只参考米白纸张、手绘墨线、圆角分区和蓝绿紫橙配色，不复制原图结构或具体元素。
- 画幅：横向 3:2 左右；每图只解释一个核心关系；大标题、短标签、粗箭头、充分留白。
- 文字：中文为主；代码标识只保留必要的 `call_id`、`action_id`、`Replay`、`Pi`、`LangGraph`、`Agents SDK`。
- 禁止：密集海报、微小脚注、伪造产品 UI、装饰性长文、品牌 logo、水印。

## 七图教学任务

1. `01-boundary.png`：模型只提出工具调用；上下文、策略/审批、执行、观察、Verifier、Trace 各有边界。
2. `02-tools.png`：五工具围绕代码库，区分只读观察、受控写入、测试与差异。
3. `03-loop.png`：一轮 decide → propose → approve → execute → observe → verify；`call_id` 关联对话，`action_id` 关联副作用，不能混用。
4. `04-approval.png`：批准后的三态恢复；前态可执行、后态只补回执、第三态停止。
5. `05-context.png`：持久状态经过权威摘要与完整消息组选择，投影成有界上下文；Trace 不被压缩。
6. `06-sandbox.png`：策略/审批是控制平面，容器是执行平面；宿主 API Key 不进入容器；当前真实探针未验证。
7. `07-responsibilities.png`：手写 Loop、Pi、LangGraph、Agents SDK 与宿主的责任分布；Pi 仅源码参照，策略、隔离、账本、验收仍归宿主。

## 验收方式

逐图检查标题、节点、箭头方向和关键否定信息。图片生成后在 1440×1000 与 390×844 预览中检查；若文字错误或在手机端不可辨，保留原候选并生成新版本，不能用图注掩盖相反箭头。
