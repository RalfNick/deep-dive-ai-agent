# 第 17 章插图源

运行 `python -B -m infographic.chapter17.generate_diagrams` 重新生成七幅 SVG。图 01 的真源是本文件中的受控矢量布局及 `chapter17/fixtures/chart-*.svg` 数值约定；图 02–07 的 `.tldr` 与 SVG 都从同一 `Scene` 生成。第一图为教学排版，**不是**实验解析输入。

所有文字、刻度和箭头是可控矢量，不依赖生成式图片。检查过的内容：图 01 的 80/100 千件和 25% 公式；图 04 的坐标/审批/后验顺序；图 06 的播报与后台双时间线；图 07 的来源、时间、权限三门。图源可在 Tldraw 打开继续编辑，但手动改源后需要相应更新生成逻辑才能保持可复现。
