### 有意保留的范围裁定

- 本章没有真实模型、GPU 或线上 A/B 测试；不能由确定性夹具推导模型学习收益、统计泛化或生产安全。
- 审批注册表是当前进程的可信接口，不是持久 IAM 或签名服务。直接修改 Python 私有注册表、任意构造进程内部状态，不是本实验宣称抵御的攻击路径；已报告的漏洞均通过正常 API 复现。
- 敏感检测只覆盖教学标记与字段，近似去重只覆盖登记家族，不是一般 PII 检测、自然语言提示注入或自动语义去重方案。
- 回滚只恢复已知版本指针，不补偿已经发生的外部副作用，也不构成真实生产流量控制器。
- `revoked_source_ids` 按正文定义指反馈引用，不额外声称自动实现来源主体的完整身份生命周期。当前 `UsePolicy` 必须由可信调用方提供并在消费时复查。
- reviewer 的只读范围不含修改预览或最终站点构建；最终元数据不是被跳过的交付，实际结果在版本记录中保存。

这些裁定不将四项重要问题降级：有限解释器的动作顺序、来源授权、回放内容绑定和旧证据复用本来就在本章承诺内，因此已修复。
