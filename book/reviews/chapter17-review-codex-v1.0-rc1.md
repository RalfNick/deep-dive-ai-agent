# 第 17 章双视角审稿：v1.0-rc1

日期：2026-09-30。对象：本地候选 `book/chapter17.md`、七图、`chapter17/` 教学实验与资料台账。本报告是作者侧审稿，不是独立模型能力认证，也不是线上发布批准。

## 读者视角

**结论：可作为完整候选阅读。** 从 80 千件到 100 千件的两柱图进入，先分开图形读取、单位与相对增长率，再进入独立 CSV 核对；屏幕章节把“看见按钮”“被授权点击”“后验确认”拆成三步；实时章节区分停播、对话截断、后台取消和已提交副作用。读者无需先理解厂商 API，也能复述四幕的核心问题：看见不等于读对，读到不等于算对，看见不等于获准行动，实时不等于更快的文本消息。

正文有 36 个二/三级标题、七幅原创图、五组实验、五张比较表、13 道分层练习及完整参考答案。图 1 的 80→100 可手算 25%，截断轴案例说明视觉高度不是数值比率；固定报告展示 20 个案例各自的状态与证据，而不是笼统打一个“成功率”。桌面 1440×1000 与手机 390×844 本地预览均检查了七图加载、五张表格局部滚动、页内锚点及整页横向溢出。

**已修问题 R1（重要，首次冻结前）。** 实验 17-5 原称比较“八个规范文件”，但最终全组 bundle 加入练习结果后为九个。先用 `test_experiment_five_matches_final_bundle_file_count` 复现失败，再改为九个，章节测试通过。若不修，读者会把正确生成的第九个文件误判为异常。

**保留的阅读边界。** 本章并不教通用 OCR、图像模型训练、真实桌面集成或音频编解码；所示 SVG、屏幕和事件是固定教学样本。想把它们用于实际系统，需要另加采集质量、隐私、权限、环境隔离、失败回退与真人验收；正文的“从模拟器到真实 Computer Use”已经明确列出缺口。

## AI 与工程专家视角

**概念及数值检查。** 相对增长 `(100-80)/80=25%` 与绝对增加 `20 千件`、百分比点的单位界线一致；截断轴只改变视觉高度，不改变数据差值。`Observation`、`Decision`、`ActionReceipt`、`EventRecord` 分别承载来源/观察、回答状态、执行后验和有序事件，未把模型声称完成等同于副作用完成。报告的 `answer=10`、`unknown=7`、`blocked=2`、`refresh=1` 加总为 20；`evidence_covered=20/20` 是引用覆盖，不是任务准确率。

**安全与时序检查。** 受控 SVG 拒绝 DTD、外链、脚本与变换；CSV 拒绝重复月份、混合单位和冲突；帧时效、非等比坐标换算、审批、允许动作与后验画面均有负例；事件归约区分重复序号、冲突序号、缺号与晚到取消；输出拒绝越界、已有目录及链接/reparse 父目录。报告和练习以固定序列生成，两个新目录的九文件分别逐字节一致。它们证明实现的**确定性边界**，不证明模型感知能力或真实桌面安全性。

**已修问题 R2（重要，首次冻结前）。** 教学用外部实体 URI 在源码中与仓库“作者机器路径”扫描规则相撞，导致仓库合同及 Git 历史扫描失败。先复现失败，再将当前样本换成不可解析的 HTTPS 示例域；旧本地提交不重写，仅对四个已核实 Git blob 的七行教学夹具作对象 ID、路径、行号、问题类型完全匹配的历史豁免，并为其加反例测试。当前树扫描与所有历史密钥扫描不豁免；完整历史扫描恢复通过。

**来源检查。** 产品职责只映射到 2026-09-30 核对的 OpenAI、Anthropic 官方指南；ChartQA、ChartQAPro 与 ScreenSpot-Pro 仅作为研究问题和失败边界来源。未据论文结果给厂商排名，未把官方 API 行为原样投射到本章中性事件名。
