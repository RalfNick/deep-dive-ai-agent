Review 日期：2026-08-10。对象：`book/chapter3.md`、`chapter3/` 实验与初版 PDF。

## 普通读者视角

### 结论

章节主线清楚：从“答案正确但文件没变”的冲突进入，逐步扩展到工具协议、状态、停止、错误、验收和框架。`parse_price()` 贯穿了定义、公式、实验和验收，降低了概念切换成本。实验命令不需要 API Key，输出中可以看到真正的文件状态与测试退出码。

### 发现与处理

| 优先级 | 发现 | 处理 |
| --- | --- | --- |
| P1 | 状态/策略公式对初学者略抽象，缺少立即映射 | 已在公式后补充 `parse_price()` 的逐步口语翻译 |
| P1 | 初版 PDF 最后一页只有一条脚注，阅读节奏断裂 | 脚注改为双栏紧凑版，重新渲染逐页检查 |

| P2 | 18 道练习数量偏多 | 按基础/实验/设计分轨；读者不必顺序完成全部题 |

## AI 工程专家视角

### 结论

章节正确地区分了工具提议与执行、协议结束与任务验收、推理闭环与训练闭环。没有把 ReAct 等同于暴露完整思维链，也没有宣称 Schema、单元测试或框架自动解决权限与业务正确性。

### 发现与处理

| 优先级 | 发现 | 处理 |
| --- | --- | --- |
| P1 | 验收通过若不绑定状态版本，存在 TOCTOU 漏洞 | 新增“验收证据必须绑定状态版本”，连接 Trace digest 与不可变制品 |
| P1 | 一轮多个工具调用不等于可以并行执行 | 新增依赖、竞态与 Harness 并发决策边界 |
| P1 | 原始工具异常直接回传模型可能泄露密钥或绝对路径 | 新增模型可见错误与高权限诊断日志分层 |
| P2 | Windows 路径规范化曾误拒合法文件 | 根目录先 `resolve()`；保留合法路径和 `../secret.txt` 回归测试 |
| P2 | 确定性策略不能证明真实模型的工具选择能力 | 正文、README 与小结均明确证据边界；模型评测留到第 13 章 |
