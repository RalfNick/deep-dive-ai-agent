# 已实现与未实现

## 已实现

- `contracts.py` / `fixtures.py`：冻结任务、来源、结果、事件、提案和回执合同；20个案例；相对路径及重解析点边界。
- `context.py` / `evidence.py`：真实文件读取、当前版本与资格、最小事实片段、来源与发送摘要；冲突、缺项、权限出口；验收时重新加载来源。
- `runtime.py` / `budget.py`：有界子任务、独立尝试、结果与实际生产者绑定、当前控制者交接、停止和迟到拒绝；全局账本、子树收紧额度、有限重试、验证保留。
- `workspace.py` / `integration.py` / `verifier.py`：独立快照、带基线提案、单写者、显式批准、动作回执重放；真实4项可信测试与独立行为探针。
- `system.py` / `cases.py`：知识与修复两路；策略由固定决策驱动，结果从真实工具观察构造；同目标单控制器与团队对照嵌在第一组，不重复计入20案。
- `reporting.py` / `output.py`：指标派生、Schema与跨记录校验；接纳、提交与最终验证事件须与结果/回执的身份、摘要和计数关联；规范字节、新目录排他输出、8文件哈希+最后写manifest。
- `exercise_solutions.py`：13题；计算复算，代码题实际运行，证据引用检查。

## 未实现

- 真实模型自主规划、真实并发调度及模型能力评测。`ScriptedPolicy` / `ObservedScriptedPolicy` 是决策替身；context实际进入观察但没有语言理解模型。
- 通用语义蕴含、Embedding、向量检索、重排。知识工具使用明确事实索引；不能将它说成完整生产RAG。
- 操作系统沙箱或任意不可信仓库执行。路径守卫是程序内策略，可信夹具测试不提供OS隔离；没有Docker验证。
- 跨进程持久账本、恢复服务、事务扣费、分布式单写者。当前回执幂等基于本次RunState；重复finish回放原验证，不是对验收后外部修改进行重新审计。
- 三方语义合并、自动解决旧补丁或资料冲突。旧提案明确拒绝；后续重做/人工处理属于扩展。
- 生产身份服务、租户体系、审批恢复与补偿回滚。`--approve`只授权本次教学修复，取消不撤销已执行动作。
- Token/费用测量、公共Benchmark排名、全书Runtime整合、发布部署。

完整规范包中的状态是机制验收结论，不是模型成绩。`answer`验收知识来源与覆盖，`verified`验收真实修复；`unknown`、`blocked`、`conflict`、`needs_approval`和`stopped`分别保留不同原因。任何一种状态都不应通过主Agent润色强行改成成功。

`input_refs` 是本次任务需要装配的事实键，不是不可扩张的授权集合；创建查证任务可以按输出要求选键，但不能扩大身份、来源、工具、写入权限。子任务工具额度计入自身及后代（含重试与实际提交），最终验证只从根任务保留支付。教学 handoff 限制当前控制者发起、未结束任务接管；它不禁止委派 Worker 执行局部工作，也不提供通用对话转接服务。

本地预览只支持 `chapter18/preview-pages/` 的直接 HTML 文件，默认 `index.html`；不提供任意层级输出位置及通用静态站点复制。知识 quickstart 当前只展示状态、计数和引用摘要，没有输出逐条知识结论；读者可在规范 JSON 的 `evidence_verdict` 中查阅，终端呈现增强延后。
