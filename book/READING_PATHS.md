## 先看到一个结果，再选择阅读路线

环境或命令不熟悉时，先读[附录A的最短起步](appendix-a.md)。在仓库根目录执行：

```powershell
python -X utf8 -B chapter3/agent_loop.py
```

它用固定决策驱动真实文件修改与测试，不调用模型。先找到“原来失败、修改后通过、验收接受”三个转折，再从第1章建立模型基础。它不是第三章取代前两章，而是让后面的概念先有一个可观察对象。

默认命令从仓库根目录运行；某章明确要求进入子目录时按说明执行，并在后续根目录命令前返回。按章安装依赖，不需要先安装全书所有框架。每次动手先回答四个问题：输入是什么、要得到什么、什么算失败、去哪里看验收证据。

## 三条路线

- **系统入门**：附录A → 第1–4章 → 第5–8章 → 第9–12章。第一遍跳过标为“进阶”的完整字段、优化器公式与存储细节；先能复述每章的一条输入—行动—结果链。
- **工作与工程实践**：已有模型基础时，从第3–4章进入，接第5–6章和第9–14章，再读第16、18章。重点看最小实验、审批、恢复、评估和诊断；将固定案例变成自己任务的验收条件，不直接放开未知代码执行。
- **学习与研究扩展**：先掌握第2章三种监督信号，再读第13–15章的统计、数据和目标函数，接第16–18章。区分机制验证、真实模型测量和生产证据；没有运行的路线保留为未知，不补造结果。

这些路线只是入口，不要求跳读者已经掌握被跳过的所有实现。某个术语挡住阅读时，回到对应前章或附录补桥，再继续当前问题。

## 复习与版本
